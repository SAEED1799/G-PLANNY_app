# GPlanny Application

A new Flutter project.

## 📌 About GPlanny

The name **GPLANNY** comes from "GROUP PLANNY," which stands for group planning to ensure quality and correctness, both in organization and in interactions with group members and their audience. The goal is to facilitate honest, reliable, and professional planning.

### 🎨 Logo
The logo is designed with interesting colors symbolizing love and shared life among people.

## 📖 Overview
GPLANNY is an app developed by team members using the **DART** programming language, implemented in 2017 by **GOOGLE**. Its key advantage is versatility—it supports multiple platforms beyond Android. The app integrates **FIREBASE** as its database, storing user data and activities.

### 🎯 Purpose
GPLANNY aims to resolve organizational challenges within associations or group activities. It streamlines manpower allocation, task organization, and financial management (including payments and donations). The app is structured into two main roles:

1. **Users**
2. **Managers**

## 👥 User Role
Users are at the core of the app, allowing them to:
- Join and explore organizational activities
- Register and log in with a username and password
- View an intuitive home screen displaying relevant content
- Access personal data stored securely in the database

## 🏢 Manager Role
Managers have a different interface with additional administrative features:
- Overview of the number of users and activities
- Financial summaries, including required payments and planned expenses
- Smart search and analytics tools to optimize management
- The ability to assign or modify administrative roles

## 🏗️ Project Structure
The app follows a structured approach with multiple folders:

### 🔹 **Core Folders**
- **WEB, ANDROID, IOS, LIB**: Contain platform-specific resources
- **LIB**: The primary folder for coding, containing key components

### 📂 **LIB Subfolders**

#### 1️⃣ **Controllers** (Handles Data & Logic)
- **VOLUNTEER CONTROLLER**: Manages user details, calculates age, removes users, and assigns admin roles
- **AUTH CONTROLLER**: Manages login authentication and user verification
- **PROJECT CONTROLLER**: Handles activity updates, budgeting, and participant upgrades
- **SEARCH CONTROLLER**: Implements smart search functionality
- **MAIN CONTROLLER**: Directs users and activities within the app

#### 2️⃣ **Utils**
- Contains helper functions for linking controllers with the UI

#### 3️⃣ **View** (Handles UI)
- **SCREENS**: Displays home screens for users and managers
- **MODULES**: Contains core objects representing users and activities
- **WIDGETS**: Defines UI components, buttons, and search elements
